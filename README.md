
# Weather Dashboard

A responsive weather dashboard built using HTML, CSS, and JavaScript.

This application allows users to search for cities worldwide and view weather forecasts, precipitation radar, and air quality information.

## Features

- Search for cities worldwide
- Current temperature and weather conditions
- Humidity and wind speed
- 12-hour weather forecast
- 5-day weather forecast
- Weather condition icons
- Hourly precipitation probability
- Interactive precipitation radar
- Air Quality Index (AQI) and categories
- Responsive design for mobile and desktop
- Error handling for invalid city searches
- Accessible search form and status messages

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Open-Meteo APIs
- Leaflet.js
- OpenStreetMap
- RainViewer

## What I Learned

- Fetching data from external APIs
- Working with asynchronous JavaScript
- Using async/await and fetch()
- Manipulating the DOM
- Creating dynamic forecast cards
- Handling API errors
- Building responsive layouts with CSS
- Integrating interactive maps
- Improving website accessibility

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run the project using a local development server.
4. Search for a city to view weather information.

## Data Sources

Weather forecasts and air quality estimates are provided by Open-Meteo.

Map data is provided by OpenStreetMap, with interactive mapping powered by Leaflet.

Recent precipitation radar imagery is provided by RainViewer.
